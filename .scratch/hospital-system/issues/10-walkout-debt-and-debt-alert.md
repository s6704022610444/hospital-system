# 10: Walkout Debt Policy, Void/Refund & Cross-Visit Outstanding Balance Alert

**What to build:** พัฒนาฟังก์ชันปรับสถานะ Visit เป็น `unpaid_debt` สำหรับเจ้าหน้าที่การเงิน (`cashier`) ในกรณีผู้ป่วยไม่ชำระเงินและเดินทางออกจากโรงพยาบาล พร้อมบันทึกยอดหนี้ค้างชำระ (`outstanding_balance`) ลงในโปรไฟล์ของผู้ป่วย (HN), พัฒนากระบวนการยกเลิกใบเสร็จและคืนเงิน (Void / Refund) ที่ต้องทำผ่านเจ้าหน้าที่การเงินเท่านั้นพร้อมระบุเหตุผลและบันทึก Audit Record, และสร้างแถบแจ้งเตือนสีแดงเด่นชัด (**Outstanding Balance Alert Banner**) บนหน้าจอเวชระเบียน (`registrar`) และหน้าจอพยาบาลคัดกรอง (`nurse`) เมื่อผู้ป่วย HN ที่มียอดหนี้ค้างชำระกลับมาเข้ารับบริการในครั้งถัดไป

**Blocked by:** 09 (Consolidated Invoicing, Simulated QR Payment & Pharmacy Dispensing)

**Status:** ready-for-agent

- [ ] เจ้าหน้าที่การเงินสามารถปรับสถานะ Visit ที่ค้างชำระเป็น `unpaid_debt` และระบบบวกยอดหนี้สะสมเข้าโปรไฟล์ผู้ป่วย
- [ ] มีขั้นตอน Void / Refund ใบเสร็จรับเงินที่ต้องทำผ่านการเงินหรือแอดมินเท่านั้น โดยไม่มีการคืนเงินอัตโนมัติ
- [ ] เมื่อเวชระเบียนค้นหาหรือเปิด Visit ให้คนไข้ที่มียอดค้างชำระ ระบบแสดงแถบสีแดงแจ้งยอดหนี้ค้างและวันที่รับบริการเดิมทันที
- [ ] หน้าจอคัดกรองพยาบาลแสดงป้ายแจ้งเตือนหนี้ค้างชำระ เพื่อแนะนำให้คนไข้ไปเคลียร์ค่าใช้จ่ายเดิม
- [ ] มี Test Suite ทดสอบการปรับเป็นหนี้สูญ, การทำ Void/Refund, และการตรวจจับหนี้ค้างชำระข้าม Visit บนหน้าจอเวชระเบียน
